# BSG

**Bible Study Guide & Six-Month Reading Ledger**

A modern, responsive React + TypeScript application to guide and track Bible reading across 180 days (1,189 chapters, ~6-7 chapters per day), supporting multi-reader tracking, streaks, and progress visualization.

## Features
- **180-Day Reading Schedule**: Covers all 1,189 chapters from Genesis through Revelation.
- **Dynamic Progress Ribbon**: Visual progress tracker with signature ribbon tail and percentage completion.
- **Reader Identity & Multi-user Support**: Join a shared ledger or start a new challenge, switch reader profiles easily.
- **Today's Reading Quick-Action**: Highlights today's assigned chapters and tracks reader completions.
- **Leaderboard & Streaks**: Real-time reader stats, day counts, and consecutive reading streaks.
- **26-Week Breakdown**: Collapsible weekly accordion view with day-by-day checkoffs and avatars.
- **Offline & Local Storage Support**: Seamless state persistence with local storage fallback.

## Tech Stack
- React 18
- TypeScript
- Vite
- Custom Dark Theme with Fraunces, Inter & IBM Plex Mono typography

## Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
